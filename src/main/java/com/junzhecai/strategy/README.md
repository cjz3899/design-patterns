# 策略模式

是一种行为模式，可以代替大量的`ifelse`。它所能帮你解决的⼀般是**具有同类可替代的⾏为逻辑算法**场景。比如：不同类型的交易方式(信⽤卡、支付宝、微信)、⽣成唯⼀ID策略(UUID、DB自增、DB+Redis、雪花算法、Leaf算法)等，都可以使用策略模式进行行为包装，供给外部使用。

其实就像点外卖时选支付方式——你点"确认支付"后，弹出微信、支付宝、银行卡几个选项，你选哪个就走哪条支付流程，而收银台（调用方）根本不需要写一堆`if(微信)…else if(支付宝)…`，只需要"把选中的方式交给对应的处理器"就行。
